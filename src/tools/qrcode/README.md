# 二维码生成

[在线使用](https://niu-hb.github.io/#/tools/qrcode) · [返回工具清单](../../../README.md)

## 功能与使用

设置尺寸与样式，下载 PNG / SVG。

## 规则与限制

二维码整体为常规方形，支持方形/圆点/圆角码点及定位角样式。

尺寸 128–1024 px，内容最多 2,000 UTF-8 字节；纠错越高容量越低。

保留至少四模块留白，提示低对比颜色；复杂内容建议增大尺寸，导出后实际扫码确认。

PNG/SVG 下载不访问输入的网址。

## 实现说明

使用 qr-code-styling 1.6.0。当前版本避免引入 Node 原生 canvas / jsdom 类型依赖；输入显式转为 UTF-8 字节，以支持中文与表情。
