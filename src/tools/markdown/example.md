### 代码行

使用 `int i = 0;` 展示行内代码。

跨行源码也可以写在一对反引号内：`int i = 0;
int j = 0;`，预览按行内代码规则合并换行。

### 缩进代码块

    int i = 0;
    int j = 0;
    for (int count = 0; count < 3; count++) {
        System.out.println(count);
    }

### 围栏代码块

```java
int i = 0;
int j = 0;
for (int count = 0; count < 3; count++) {
    System.out.println(count);
}
```

代码块支持语言标记，当前预览保留代码文本，不提供语法着色。
