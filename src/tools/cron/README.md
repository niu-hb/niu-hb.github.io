# Cron 表达式生成 / 测试

[在线使用](https://niu-hb.github.io/#/tools/cron) · [返回工具清单](../../../README.md)

## 功能与使用

选择实际使用的工具方言，输入表达式或通过分段字段、常用示例生成表达式，再校验并预览后续执行时间。输入在浏览器本地处理；工具不创建或执行定时任务。

## 字段与适用工具

字段数不是编程语言标准，相同段数也可能有不同语义。命令和用户名不计入时间字段。

| 工具方言 | 段数 | 字段顺序 | 适用环境 |
| --- | --- | --- | --- |
| Linux crontab（Vixie / Cronie） | 5 | 分、时、日、月、星期 | 操作系统工具，与语言无关 |
| node-cron 4.2.1 | 5 / 6 | 可选秒、分、时、日、月、星期 | Node.js，JavaScript / TypeScript |
| Spring Framework 5.3+ CronExpression / @Scheduled | 6 | 秒、分、时、日、月、星期 | Java / JVM |
| Quartz Java CronTrigger | 6 / 7 | 秒、分、时、日、月、星期、可选年 | Java 调度库 |

node-cron 的 5 段式将秒固定为 0；Spring 没有年字段。页面提供各方言规则对照和官方链接，不能只按段数套用其他 cron 库的规则。

## 校验与生成规则

- Linux 的日与星期同时受限时采用“或”规则；任一日或星期字段以星号开头时采用“且”规则。
- node-cron 与 Spring 必须同时满足日和星期。
- Linux、node-cron、Spring 的星期 0 / 7 表示周日；Quartz 的 1 表示周日。
- Quartz 的日和星期有且仅有一个使用问号；Spring 的问号等价于通配符。
- Spring / Quartz 支持特殊日期与月末偏移；Linux / Spring 支持常用时间宏。
- node-cron 4.2.1 不支持这些扩展，步长使用星号或范围加步长的形式，例如每 5 分钟：`*/5 * * * *`。

生成、校验和执行时间预览共用方言规则，用户输入的非法字段不会被自动改写。依赖为精确锁定的 cronjs 解析器和匹配器，工具另行处理方言差异。

## 本工具的预览范围

- 表达式最多 200 个字符；年份限 1970–2099 年。
- 星期序号限 1–5；月末偏移在 Quartz 中限 0–30、Spring 中限 1–30，不预览跨月偏移。
- Quartz 特殊日期不与列表混合。
- 不支持随机 H、C、重启触发宏、命令部分、多条表达式或 misfire / 停机补偿策略。
- 测试起点按 UTC 输入，结果按所选 IANA 时区计算并展示偏移。
- 最多预览 20 次、搜索未来 10 年；计算在独立 Worker 中进行，达到步数限制或超过两秒会停止。

这些限制属于本工具的支持范围，不代表各调度器的完整能力，也不承诺覆盖其他版本或其他 cron 库的全部扩展。
