# 田字格生成

[在线使用](https://niu-hb.github.io/#/tools/tian-grid) · [返回工具清单](../../../README.md)

## 功能与使用

生成 A4 练习纸，打印或保存 PDF。

## 规则与限制

生成一页 A4 田字格练习纸：实时更新预览，每行输入对应一行格子，空文本生成空白纸。

支持 1–20 行、1–15 列，文字按 Unicode 码点放入方格；超出行列时明确提示未显示内容。

描红模式使用浅灰文字和虚线。

打印使用 A4、100% 缩放、关闭页眉页脚，可在浏览器打印对话框保存 PDF；字体取决于设备是否安装楷体。

一次生成一页。
